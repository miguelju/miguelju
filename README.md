## Hi 👋

I have spent more than twenty years across process design, engineering
information systems, and software. Today I work in presales at
[AVEVA](https://www.aveva.com), helping owner-operators and EPCs turn
plant-lifecycle problems into connected engineering solutions.

I learned BASIC on my dad's Sinclair ZX81, then wrote, with
[Carlos](https://github.com/cmendible), a multicomponent
vapor-liquid-equilibrium calculator for our 1999 chemical-engineering thesis.
Today I am rebuilding that work in Rust and Python—and using it as a laboratory
for agentic software development.

## What I am building with AI

- **[vle](https://github.com/miguelju/vle)** — a Rust + Python thermodynamics
  engine grown from our 1999 VB6 thesis, with notebooks and bindings for Swift,
  Kotlin, and WebAssembly.
- **[vle-mcp](https://github.com/miguelju/vle-mcp)** — a typed MCP gateway where
  AI explains the question and tested scientific software supplies the answer.
- **[Simple SSH](https://github.com/miguelju/simplessh_ios)** — a native SwiftUI
  SSH client for iPhone with secure key storage and a real terminal.

I also explore MCP, self-hosted telemetry, infrastructure as code, GitOps,
Apple-platform apps, and interactive learning software.

**Working with:** Rust · Python · Go · Swift · C# · TypeScript · Terraform ·
Ansible · Docker · Kubernetes
